// activity_types.txt - custom activities registered into the DEDICATED SERVER's
// activity list at host-init (LoadCustomActivitiesFromFile).
//
// GOAL: the dedi's activity table must be a 1:1 superset of the S21 client's.
// We ship the original S21 models and anims, so content asks for S21 activity
// names. Anything the client has must exist here; anything the client does NOT
// have is unreachable by definition (an S21 model cannot bind to it) and only
// adds ids that can never translate.
//
// READ THIS BEFORE DELETING ANYTHING.
//
// The test for "does this name belong here" is whether the S3 DEDI engine has
// it -- NOT whether the S21 client has it. On 2026-06-29 that test was inverted
// and 98 names were removed because the client already covered them, which is
// exactly backwards: the client having an activity is the reason the dedi needs
// it too. Restored 2026-07-28 by diffing both engines' registration tables.
//
// Without the name on the dedi the server cannot author it and the wire
// translator has nothing to match, so the raw S3 id ships and resolves to a
// DIFFERENT, valid S21 activity on the client -- a wrong animation, not a
// missing one. Measured 9 such collisions, e.g. ACT_MP_MELEE_KNIFE played
// ACT_MP_HOVER_VEHICLE_STOP_DRIVER.
//
// Registration appends to the end of the dedi's table, so these get S3 ids that
// do not match S21's. That is fine: the wire translation is by NAME, so only
// presence matters here, never ordering.
//
// Re-registering a name the engine already has is skipped harmlessly. Names
// must start with ACT_. Lines starting with // and trailing // comments are
// ignored.
//
// Verify at boot:
//   [ACT-XLAT] map built: 975 mapped, ...
//   [ACT-XLAT] reverse S21->S3: 0 S21 activities have no S3 source
// A non-zero reverse count means this file is short again.
//
// To regenerate after a client update: re-run RE/enum_harvest_ida.py against
// both instances, then diff S21 ACT_* against S3 ACT_* -- everything S21-only
// belongs in the first block below. See RE/ENUM_DRIFT_HARVEST.md.
